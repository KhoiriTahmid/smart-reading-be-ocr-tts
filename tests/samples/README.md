# OCR sample images

`indonesian_text.png` and `indonesian_text.jpg` are synthetic, high-contrast
images containing:

```
Selamat pagi. Ini adalah teks bahasa Indonesia.
Harga buku ini Rp 25.000.
Email: budi@example.com
Telepon: 0812-3456-7890
```

They are generated by `scripts/generate_samples.py` and used by
`tests/test_ocr_integration.py`. The test is skipped unless
`RUN_OCR_INTEGRATION=1` so the default unit-test run never downloads models.
